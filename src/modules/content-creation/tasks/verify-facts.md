# verify-facts

## Task Overview

Systematically verify factual claims using multiple independent sources and established verification methodologies.

## Instructions

1. **Claim Extraction**
   - Identify all specific factual claims in the content
   - Distinguish between verifiable facts and opinions
   - Note claims that are particularly important or controversial
   - Document exact wording of claims for precise verification

2. **Source Identification**
   - Identify primary sources for each claim
   - Find multiple independent sources when possible
   - Prioritize authoritative and credible sources
   - Document source hierarchy (primary > secondary > tertiary)

3. **Verification Process**
   - Cross-reference claims against multiple sources
   - Check for consistency across independent sources
   - Identify any contradictions or discrepancies
   - Verify dates, numbers, names, and specific details

4. **Documentation Standards**
   - Record verification status for each claim
   - Note level of confidence (verified, likely, uncertain, disputed)
   - Document sources used and their credibility
   - Flag any claims that cannot be verified

5. **Red Flag Assessment**
   - Identify claims that contradict established facts
   - Note unsupported sensational claims
   - Flag potential misinformation or disinformation
   - Check for internally inconsistent claims

## Elicitation Requirements

- Get specific content or claims to be fact-checked
- Clarify verification standards and requirements
- Understand time sensitivity and scope of verification
- Confirm access to necessary resources and databases

## Output Requirements

Create a comprehensive fact-check report documenting:

- Each claim and its verification status
- Sources used and their reliability assessment
- Any contradictions or inconsistencies found
- Recommendations for handling unverified claims
