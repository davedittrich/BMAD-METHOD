# save-transcript

## Task Overview

Saves a transcript to a file.

## Instructions

1.  **Get transcript content:** Get the transcript content from the user.
2.  **Get topic:** Get the topic of the transcript.
3.  **Save to file:** Save the transcript to a file in the `src/modules/content-creation/data/transcripts/` directory. The filename should be `{{topic}}-{{date}}.md`. The file should include a metadata header with the date and topic.
