# project-collaborate

## Task Overview

(Future - Phase 3) Enable team coordination and knowledge sharing across related research projects.

## Instructions

1.  **Collaboration Space Initialization**
    - Establish a collaborative workspace for linked projects.
    - Create a shared configuration in `.bmad/config/collaboration-spaces.json`.
    - Initialize team coordination framework with participant tracking.

2.  **Team Coordination and Management**
    - Identify project participants and research team members.
    - Establish collaboration roles (e.g., lead, contributor, reviewer).

3.  **Knowledge Sharing**
    - Create a shared resource repository for templates and methodologies.
    - Establish shared source collections.

4.  **Validation and Confirmation**
    - Verify that the collaboration space was initialized.
    - Display a summary of the collaboration setup.

## Elicitation Requirements

elicit: true
format: |
Please specify:

    **Collaboration Context:**

    - Which projects should be part of this collaboration?
    - What is the primary goal of the collaboration?

    **Team Coordination:**

    - Who are the collaboration participants and what are their roles?

## Output Requirements

**Collaboration Space Establishment:**

- Collaborative workspace created for the project network.
- Shared collaboration metadata stored in `.bmad/config/collaboration-spaces.json`.

**Future (Phase 3) Output Requirements:**

- Collaborative annotation system.
- Shared analysis and synthesis workflows.
- Collaboration history and attribution tracking.

**Error Handling:**

- Clear messages for invalid project names or configuration errors.
