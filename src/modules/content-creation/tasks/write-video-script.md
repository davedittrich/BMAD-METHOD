# write-video-script

## Task Overview

Create engaging video scripts optimized for specific platforms and target audiences with strong hooks, clear structure, and retention elements.

## Instructions

1. **Pre-Production Planning**
   - Define target platform (YouTube, TikTok, Instagram, etc.)
   - Identify target audience and their preferences
   - Determine video length and format requirements
   - Establish key message and learning objectives

2. **Hook Development (First 15 seconds)**
   - Create attention-grabbing opening line
   - Promise specific value or outcome
   - Use pattern interrupts or surprising statements
   - Set clear expectations for video content

3. **Script Structure**
   - **Introduction (15-30 seconds)**: Hook + preview of content
   - **Main Content (60-80% of video)**: Core information delivery
   - **Conclusion (10-15%)**: Summary and call-to-action
   - Include natural transition phrases between sections

4. **Engagement Elements**
   - Add retention hooks throughout (questions, previews)
   - Include visual cue suggestions for editor
   - Plan interaction prompts (comments, likes, shares)
   - Design memorable quotable moments

5. **Platform Optimization**
   - Adapt pacing for platform expectations
   - Include platform-specific engagement tactics
   - Plan thumbnail and title integration
   - Consider algorithm-friendly elements

6. **Production Notes**
   - Add timing markers for key sections
   - Include suggestions for B-roll and visuals
   - Note emphasis points and tone changes
   - Specify any graphics or text overlay needs

## Elicitation Requirements

elicit: true
format: |
Please provide the following information:

**Content Requirements:**

- What is the main topic or message?
- What key points must be covered?
- What is the target audience?

**Platform Specifications:**

- Which platform is this for? (YouTube, TikTok, Instagram, etc.)
- What is the target video length?
- What format? (educational, entertainment, news, etc.)

**Style Preferences:**

- What tone should the script have? (professional, casual, energetic, etc.)
- Any specific style requirements or preferences?
- Should it include humor, storytelling, or specific techniques?

## Output Requirements

Deliver a complete video script with:

- Formatted script with timing markers
- Visual and audio cue suggestions
- Platform-specific optimization notes
- Engagement strategy elements integrated throughout
