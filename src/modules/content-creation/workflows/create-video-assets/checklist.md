# Create Video Assets Workflow Checklist

## Content Analysis

- [ ] Source content has been analyzed for video structure
- [ ] Video pacing and timing have been determined
- [ ] Visual style and approach are clearly defined

## Storyboard

- [ ] All scenes are documented with visual descriptions
- [ ] Scene transitions are specified
- [ ] Camera angles and framing are defined
- [ ] Timing/duration for each scene is indicated
- [ ] Storyboard is visually clear and actionable

## Narration Script

- [ ] Script is adapted for spoken delivery
- [ ] Script is synchronized with storyboard scenes
- [ ] Timing markers are included
- [ ] Script length matches target video duration
- [ ] Language is clear and engaging for audio format

## Audio Assets

- [ ] Audio narration has been generated or provided
- [ ] Audio quality is acceptable (clear, no distortion)
- [ ] Audio timing aligns with script and storyboard
- [ ] Audio format is compatible with video editing tools
- [ ] Backup TTS instructions are provided if needed

## Visual Assets

- [ ] All storyboard scenes have corresponding visual assets
- [ ] Visual assets match storyboard descriptions
- [ ] Image/video quality meets minimum requirements
- [ ] Assets are properly organized and labeled
- [ ] Asset file formats are compatible with video editing tools
- [ ] Alternative sourcing instructions provided if assets missing

## Assembly Instructions

- [ ] Scene sequence and timing are clearly documented
- [ ] Audio synchronization points are specified
- [ ] Transition effects are described
- [ ] Text overlays and captions are included
- [ ] Technical specifications (resolution, frame rate, format) are provided
- [ ] Video editing tool recommendations are included

## Production Kit Organization

- [ ] All files are organized in proper directory structure
- [ ] File naming is consistent and descriptive
- [ ] File manifest is complete and accurate
- [ ] Production kit path is documented
- [ ] All required assets are present and accessible

## Quality Assurance

- [ ] Storyboard review completed
- [ ] Asset inventory verified
- [ ] Technical compatibility confirmed
- [ ] Missing assets identified and documented
- [ ] Next steps are clearly communicated

## Documentation

- [ ] Production kit summary document is complete
- [ ] Asset inventory is documented
- [ ] Technical requirements are specified
- [ ] Troubleshooting notes are included
- [ ] Link to publish-video workflow is provided
