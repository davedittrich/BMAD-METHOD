# Adapt for Social Media Workflow Checklist

## Content Analysis

- [ ] Source content has been provided and is accessible
- [ ] Content has been analyzed for key themes and takeaways
- [ ] Adaptable segments and hooks have been identified
- [ ] Platform-appropriate angles have been determined
- [ ] Target platforms have been selected

## Twitter/X Thread

- [ ] Thread has compelling opening hook
- [ ] Each tweet is ≤280 characters
- [ ] Thread maintains narrative flow (5-10 tweets optimal)
- [ ] Final tweet includes clear call-to-action
- [ ] Hashtags are relevant and not excessive (2-3 max)
- [ ] Thread is engaging and shareable

## LinkedIn Content

- [ ] Main post is professional yet engaging
- [ ] Post length is appropriate (under 3000 characters)
- [ ] Clear value proposition is present
- [ ] Industry-relevant insights included
- [ ] Call-to-action encourages engagement
- [ ] Carousel deck has 5-10 slides
- [ ] Each carousel slide has headline + key point
- [ ] Carousel tells coherent story
- [ ] Visual requirements documented

## Instagram Content

- [ ] Carousel post has up to 10 slides
- [ ] Carousel captions are short and punchy
- [ ] Reels script is 30-60 seconds
- [ ] Reels hook grabs attention in first 3 seconds
- [ ] Visual-first approach maintained
- [ ] Hashtag strategy includes mix of broad and niche tags (10-15)
- [ ] Call-to-action is clear
- [ ] Visual requirements documented

## Facebook Post

- [ ] Post has conversational, community-building tone
- [ ] Clear hook is present
- [ ] Content encourages comments and shares
- [ ] Link placement is strategic
- [ ] Emoji usage is moderate and appropriate

## YouTube Shorts Script

- [ ] Script is 15-60 seconds
- [ ] Immediate hook in first 2 seconds
- [ ] Fast pacing maintained
- [ ] On-screen text callouts specified
- [ ] Visual directions are clear
- [ ] Subscribe CTA included at end
- [ ] Final frame is thumbnail-friendly
- [ ] Vertical format requirements documented (1080x1920)

## TikTok Script

- [ ] Script is 15-60 seconds
- [ ] Pattern interrupt hook is present
- [ ] Fast cuts and visual variety specified
- [ ] On-screen text elements included
- [ ] Sound/music recommendations provided
- [ ] Trend-aware approach demonstrated
- [ ] Hashtag strategy includes #FYP + niche tags
- [ ] Vertical format requirements documented (1080x1920)

## Visual Asset Requirements

- [ ] Image specifications documented (dimensions, format, style)
- [ ] Video clip requirements specified (if applicable)
- [ ] Text overlay suggestions provided
- [ ] Brand element placement described
- [ ] Color scheme recommendations included
- [ ] Requirements organized by platform
- [ ] Asset creation guidance is clear

## Posting Schedule

- [ ] Optimal posting times recommended for each platform
- [ ] Content sequencing strategy provided
- [ ] Cross-platform coordination considered
- [ ] Time zone considerations noted
- [ ] Schedule maximizes reach potential

## Content Kit Organization

- [ ] All content organized in proper directory structure
- [ ] Files are properly named and labeled
- [ ] Master content kit document is complete
- [ ] Content kit path is documented
- [ ] All platform content is included

## Quality Assurance

- [ ] All content maintains consistent message across platforms
- [ ] Platform-specific best practices followed
- [ ] Character/length limits respected
- [ ] Brand voice maintained (or adapted appropriately)
- [ ] Grammar and spelling checked
- [ ] Links and CTAs are accurate

## Documentation

- [ ] Content analysis summary is complete
- [ ] Visual asset requirements are clear
- [ ] Posting schedule is actionable
- [ ] Performance tracking guidance provided
- [ ] Next steps clearly communicated
- [ ] Link to promote-content workflow provided
