# Publish Video Workflow Checklist

## Pre-Publication

- [ ] Video file is accessible and in valid format
- [ ] Video meets target platform requirements (size, duration, format)
- [ ] Target platform has been selected
- [ ] Platform API credentials are configured (or manual upload planned)

## Metadata

- [ ] Video title is compelling and platform-optimized
- [ ] Description is complete and includes relevant links/credits
- [ ] Tags are relevant and optimized for discovery
- [ ] Category is appropriate
- [ ] Metadata follows platform best practices
- [ ] Metadata has been reviewed and approved

## Thumbnail

- [ ] Custom thumbnail has been created or selected (if desired)
- [ ] Thumbnail meets platform size requirements
- [ ] Thumbnail is visually appealing and representative of content
- [ ] Thumbnail includes text overlay if appropriate
- [ ] Thumbnail file format is compatible

## Platform Settings

- [ ] Privacy setting selected (public, unlisted, private, scheduled)
- [ ] Monetization preference configured (if applicable)
- [ ] Age restriction setting configured
- [ ] Comments setting configured
- [ ] Platform-specific features configured (duet/stitch, downloads, etc.)

## Authentication

- [ ] Platform API authentication successful
- [ ] OAuth tokens are valid and stored securely
- [ ] API rate limits are within acceptable range
- [ ] Backup manual upload instructions available if API fails

## Upload Process

- [ ] Video file size verified against platform limits
- [ ] Upload initiated successfully
- [ ] Upload progress monitored
- [ ] Upload completed without errors
- [ ] Video processing on platform completed

## Thumbnail Upload

- [ ] Custom thumbnail uploaded (if provided)
- [ ] Thumbnail set successfully on video
- [ ] Thumbnail displays correctly on platform

## Publication

- [ ] All settings applied correctly
- [ ] Video status finalized (published, scheduled, or private as intended)
- [ ] Video URL obtained
- [ ] Video accessible at published URL
- [ ] Metadata displays correctly on platform

## Post-Publication

- [ ] Publication report generated
- [ ] Video URL shared with user
- [ ] Engagement recommendations provided
- [ ] Analytics tracking configured or instructions provided
- [ ] Promotion strategy recommendations delivered
- [ ] Link to promote-content workflow provided

## Error Handling

- [ ] Upload errors handled gracefully
- [ ] Retry logic available for failed uploads
- [ ] Manual upload fallback instructions provided if needed
- [ ] Error messages are clear and actionable

## Documentation

- [ ] Publication summary complete
- [ ] All settings documented
- [ ] Video URL recorded
- [ ] Next steps clearly communicated
