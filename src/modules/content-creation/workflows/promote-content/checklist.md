# Promote Content Workflow Checklist

## Content Analysis

- [ ] Content to promote has been identified and is accessible
- [ ] Content has been analyzed for promotional hooks and angles
- [ ] Key benefits and audience value propositions identified
- [ ] Promotional objectives are clearly defined
- [ ] Target audience is understood

## Campaign Strategy

- [ ] Target platforms selected based on audience and objectives
- [ ] Campaign duration and structure determined
- [ ] Number of posts per platform defined
- [ ] Campaign aligns with promotional objectives
- [ ] Resources (time, budget, team) are adequate

## Promotional Posts

- [ ] All promotional posts created for selected platforms
- [ ] Multiple angles and hooks used across posts
- [ ] Posts follow platform-specific best practices
- [ ] Variety in approach (question, stat, quote, story, benefit)
- [ ] Clear calls-to-action included
- [ ] Links are correct and functional
- [ ] Hashtags are relevant and strategic
- [ ] Character/length limits respected

## A/B Testing

- [ ] A/B test variations created (if applicable)
- [ ] Variations test different hooks, formats, or CTAs
- [ ] Testing methodology documented
- [ ] Success metrics for tests defined

## Visual Assets

- [ ] Visual asset recommendations provided for each post
- [ ] Image dimensions and formats specified
- [ ] Design suggestions documented
- [ ] Text overlay recommendations included
- [ ] Link preview optimization considered
- [ ] Visual assets created or sourced (if executing now)

## Posting Schedule

- [ ] Optimal posting times identified for each platform
- [ ] Posts distributed appropriately across campaign duration
- [ ] Schedule avoids over-posting
- [ ] Schedule maximizes reach potential
- [ ] Cross-platform coordination considered
- [ ] Time zones accounted for

## Scheduling & Execution

- [ ] Posting method selected (manual, scheduling tool, API)
- [ ] Scheduling export created (if using scheduling tool)
- [ ] Export format compatible with selected tool
- [ ] API configuration complete (if using API scheduling)
- [ ] Manual posting instructions clear (if posting manually)
- [ ] All posts ready to queue or schedule

## Engagement Strategy

- [ ] Engagement strategy documented
- [ ] Response templates prepared for common scenarios
- [ ] Team roles and responsibilities defined
- [ ] Monitoring plan established
- [ ] Amplification tactics identified

## Tracking & Analytics

- [ ] UTM parameters configured for all links
- [ ] UTM naming convention consistent
- [ ] Key metrics identified for each platform
- [ ] Success criteria defined based on objectives
- [ ] Tracking tools selected and configured
- [ ] Google Analytics (or equivalent) set up
- [ ] Baseline metrics recorded (if available)

## Campaign Kit Organization

- [ ] All files organized in proper directory structure
- [ ] Posts organized by platform
- [ ] File naming is consistent
- [ ] Campaign kit path documented
- [ ] Master campaign document complete
- [ ] All required files present and accessible

## Quality Assurance

- [ ] All posts proofread for grammar and spelling
- [ ] Links tested and verified
- [ ] UTM parameters tested
- [ ] Visual assets reviewed
- [ ] Schedule reviewed for conflicts
- [ ] Team has reviewed campaign materials

## Pre-Launch

- [ ] All promotional posts approved
- [ ] Visual assets finalized
- [ ] Analytics tracking verified
- [ ] Posting schedule confirmed
- [ ] Team briefed on campaign
- [ ] Response templates accessible
- [ ] Monitoring plan in place

## Documentation

- [ ] Campaign overview documented
- [ ] Content analysis summary complete
- [ ] Execution plan clear and actionable
- [ ] Success criteria documented
- [ ] Optimization recommendations provided
- [ ] Next steps clearly communicated

## Post-Campaign

- [ ] Performance data collected
- [ ] Results analyzed against success criteria
- [ ] Learnings documented for future campaigns
- [ ] A/B test results analyzed (if applicable)
- [ ] Optimization opportunities identified
