# Argument Structure Assessment Checklist

_Based on T. Edward Damer's "Attacking Faulty Reasoning" methodology_

Use this checklist to systematically evaluate argument structure using Damer's five criteria for good arguments and principles of effective discussion.

## Damer's Code of Intellectual Conduct

### Discussion Prerequisites

- [ ] **Fallibility Principle**: Acknowledge that your initial view may not be the most defensible position
- [ ] **Truth-Seeking Principle**: Earnestly search for truth by examining alternative positions seriously and allowing others to present arguments
- [ ] **Clarity Principle**: Ensure arguments are free of linguistic confusion and carefully define key terms
- [ ] **Burden-of-Proof Principle**: The person making a claim bears the responsibility of proving it

### Charitable Engagement

- [ ] **Principle of Charity**: Reformulate opponent's arguments in their strongest possible version, giving benefit of doubt
- [ ] **Fair Representation**: Present opposing positions accurately and completely
- [ ] **Respectful Discourse**: Engage with ideas rather than attacking persons
- [ ] **Good Faith Assumption**: Assume opponents are arguing in good faith unless proven otherwise

### Resolution Standards

- [ ] **Suspension-of-Judgment Principle**: Withhold judgment if no position is well-defended or positions seem equally strong
- [ ] **Resolution Principle**: Consider an issue resolved when one argument meets structural and evidential standards more successfully than alternatives
- [ ] **Progress Recognition**: Acknowledge when discussion has advanced understanding
- [ ] **Intellectual Humility**: Accept when your position has been effectively challenged

## Damer's Five Criteria Assessment

### 1. Structural Criterion Violations

**Definition**: Use well-formed arguments without internal contradictions or invalid logical inferences

- [ ] **Internal Consistency**: No premises contradict each other
- [ ] **Premise-Conclusion Consistency**: Premises don't contradict the conclusion
- [ ] **Non-Circular Reasoning**: Conclusion not assumed in premises (no begging the question)
- [ ] **Valid Logical Form**: Conclusion follows logically from premises
- [ ] **Proper Inference Rules**: Valid inference patterns used throughout

**Common Structural Fallacies to Check**:

- [ ] **Begging the Question**: Conclusion assumed in premises
- [ ] **Self-Contradiction**: Premises contradict each other or the conclusion
- [ ] **Invalid Syllogism**: Formal logical errors in deductive reasoning
- [ ] **Affirming the Consequent**: "If A then B; B; therefore A"
- [ ] **Denying the Antecedent**: "If A then B; not A; therefore not B"
- [ ] **Undistributed Middle**: Middle term not distributed in at least one premise
- [ ] **Illicit Major/Minor**: Major or minor term distributed in conclusion but not premise
- [ ] **Modal Fallacies**: Incorrect reasoning about necessity and possibility
- [ ] **Temporal Fallacies**: Incorrect reasoning about time relationships

### 2. Relevance Criterion Violations

**Definition**: Provide reasons that genuinely evidence the conclusion

- [ ] **Direct Relevance**: Each premise directly supports the conclusion
- [ ] **Logical Connection**: Clear logical connection between evidence and claim
- [ ] **On-Topic Focus**: Arguments stay focused on the issue at hand
- [ ] **Appropriate Evidence Type**: Type of evidence matches type of claim
- [ ] **Material Connection**: Evidence materially affects probability of conclusion

**Common Relevance Fallacies to Check**:

- [ ] **Ad Hominem**: Attacking person instead of argument
  - [ ] **Abusive**: Direct personal attack
  - [ ] **Circumstantial**: Attacking person's circumstances or motivations
  - [ ] **Tu Quoque**: "You too" - pointing out opponent's hypocrisy
- [ ] **Red Herring**: Introducing irrelevant information to distract
- [ ] **Straw Man**: Misrepresenting opponent's position
- [ ] **Appeal to Force**: Using threats instead of reasons
- [ ] **Appeal to Pity**: Using sympathy instead of evidence
- [ ] **Appeal to Fear**: Using fear to avoid rational evaluation
- [ ] **Appeal to Flattery**: Using praise to avoid critical evaluation
- [ ] **Genetic Fallacy**: Rejecting claim based on irrelevant origin
- [ ] **Appeal to Tradition**: "We've always done it this way"
- [ ] **Appeal to Novelty**: "This is new, therefore better"
- [ ] **Appeal to Popularity/Bandwagon**: Argument from majority opinion
- [ ] **Poisoning the Well**: Pre-emptive attack on opponent's credibility

### 3. Acceptability Criterion Violations

**Definition**: Use reasons likely to be accepted by rational people

- [ ] **Source Credibility**: Sources are credible and authoritative
- [ ] **Evidence Verifiability**: Evidence can be independently verified
- [ ] **Reasonable Assumptions**: Underlying assumptions are reasonable
- [ ] **Clear Definitions**: Key terms clearly and consistently defined
- [ ] **Factual Accuracy**: Factual claims are accurate and up-to-date

**Common Acceptability Fallacies to Check**:

- [ ] **Appeal to Ignorance**: "We don't know it's false, so it's true"
- [ ] **False Dilemma**: Only two options presented when more exist
- [ ] **Complex Question**: Question contains unjustified assumptions
- [ ] **Equivocation**: Using words with different meanings in same argument
- [ ] **Division Fallacy**: What's true of whole must be true of parts
- [ ] **Composition Fallacy**: What's true of parts must be true of whole
- [ ] **Questionable Cause**: Assuming causation without sufficient evidence

### 4. Sufficiency Criterion Violations

**Definition**: Provide enough relevant and acceptable reasons to justify the conclusion

- [ ] **Adequate Evidence Quantity**: Sufficient amount of evidence provided
- [ ] **Evidence Diversity**: Multiple types of evidence when appropriate
- [ ] **Proportional Strength**: Evidence strength matches claim strength
- [ ] **Complete Coverage**: Evidence covers all aspects of the claim
- [ ] **Statistical Adequacy**: Statistical evidence meets adequacy standards

**Common Sufficiency Fallacies to Check**:

- [ ] **Hasty Generalization**: Drawing broad conclusions from limited evidence
- [ ] **Insufficient Sample**: Statistical conclusions from inadequate samples
- [ ] **Anecdotal Evidence**: Over-relying on personal stories
- [ ] **Cherry Picking**: Selecting only favorable evidence
- [ ] **False Analogy**: Drawing conclusions from weak analogies
- [ ] **Slippery Slope**: Assuming extreme consequences without justification
- [ ] **Post Hoc Ergo Propter Hoc**: Assuming causation from temporal sequence
- [ ] **Correlation Implies Causation**: Confusing correlation with causation
- [ ] **Oversimplified Cause**: Ignoring multiple causal factors
- [ ] **Survivorship Bias**: Focusing only on survivors while overlooking failures
- [ ] **Base Rate Fallacy**: Ignoring prior probability when making judgments

### 5. Rebuttal Criterion Violations

**Definition**: Anticipate and effectively address potential serious criticisms

- [ ] **Counterargument Identification**: Major counterarguments identified
- [ ] **Fair Representation**: Counterarguments represented fairly and completely
- [ ] **Direct Response**: Counterarguments directly addressed, not dismissed
- [ ] **Evidence-Based Refutation**: Refutations supported by evidence
- [ ] **Alternative Consideration**: Alternative explanations considered

**Common Rebuttal Fallacies to Check**:

- [ ] **Straw Man**: Misrepresenting counterarguments to easily defeat them
- [ ] **Avoiding the Issue**: Not addressing the real counterarguments
- [ ] **Poisoning the Well**: Pre-emptively discrediting opposition
- [ ] **Tu Quoque**: "You do it too" instead of addressing the argument
- [ ] **Appeal to Hypocrisy**: Focusing on opponent's inconsistency rather than argument

## Normal Form Analysis

### Argument Reconstruction

- [ ] **Premise Identification**: All premises clearly identified and numbered
- [ ] **Hidden Premises**: Implicit assumptions made explicit
- [ ] **Intermediate Conclusions**: Sub-conclusions identified if present
- [ ] **Main Conclusion**: Primary conclusion clearly stated
- [ ] **Logical Structure**: Argument structure visually mapped or diagrammed

### Standard Form Requirements

- [ ] **Premise Numbering**: All premises clearly numbered
- [ ] **Conclusion Designation**: Conclusion clearly marked (Therefore, Thus, So)
- [ ] **Logical Indicators**: Premise and conclusion indicators properly used
- [ ] **Complete Statements**: Each premise and conclusion expressed as complete statement
- [ ] **Clarity and Precision**: Each statement clear and unambiguous

## Fallacy Categories by Criterion

### Structural Fallacies

- [ ] **Circular Reasoning/Begging the Question**: P1: A is true because B. P2: B is true because A. C: Therefore A.
- [ ] **Self-Contradiction**: Premises contradict each other or conclusion
- [ ] **Invalid Inference**: Conclusion doesn't follow from premises

### Relevance Fallacies

- [ ] **Personal Attack (Ad Hominem)**: Attacking arguer rather than argument
- [ ] **Appeal to Force (Ad Baculum)**: Using threats to compel acceptance
- [ ] **Appeal to Pity (Ad Misericordiam)**: Using sympathy to gain acceptance
- [ ] **Mob Appeal (Ad Populum)**: "Everyone believes it, so it's true"
- [ ] **Appeal to Tradition**: "We've always done it this way"
- [ ] **Appeal to Novelty**: "It's new, so it must be better"
- [ ] **Red Herring**: Introducing irrelevant information
- [ ] **Straw Man**: Misrepresenting opponent's position

### Acceptability Fallacies

- [ ] **Appeal to Ignorance**: Lack of disproof treated as proof
- [ ] **False Dilemma**: Presenting only two options when more exist
- [ ] **Loaded Question**: Question contains controversial assumptions
- [ ] **Equivocation**: Same word used with different meanings
- [ ] **Division**: Assuming parts have properties of whole
- [ ] **Composition**: Assuming whole has properties of parts

### Sufficiency Fallacies

- [ ] **Hasty Generalization**: Inadequate sample size for conclusion
- [ ] **Anecdotal Evidence**: Personal experience treated as universal truth
- [ ] **False Analogy**: Poor comparison used as evidence
- [ ] **Causal Oversimplification**: Complex causation reduced to single cause
- [ ] **Slippery Slope**: Assuming chain of events without justification
- [ ] **Appeal to Ignorance**: "No one has proven it false"

### Rebuttal Fallacies

- [ ] **Avoiding the Issue**: Not addressing main counterarguments
- [ ] **Attacking the Fallacy**: Focusing on opponent's errors rather than defending position
- [ ] **Circumstantial Ad Hominem**: "You would say that because..."
- [ ] **Poisoning the Well**: Discrediting source before examining argument
- [ ] **Tu Quoque**: "You're a hypocrite" instead of addressing argument

## Quality Assessment Framework

### Argument Strength Levels

- [ ] **Weak Argument**: Violates multiple criteria significantly
- [ ] **Questionable Argument**: Violates some criteria or meets criteria marginally
- [ ] **Acceptable Argument**: Meets most criteria adequately
- [ ] **Strong Argument**: Meets all criteria convincingly
- [ ] **Compelling Argument**: Exceeds criteria and anticipates objections

### Documentation Standards

- [ ] **Fallacy Identification**: Specific fallacies identified by name and type
- [ ] **Criterion Violations**: Clear indication of which criteria are violated
- [ ] **Evidence Quality**: Assessment of evidence quality and relevance
- [ ] **Structural Analysis**: Complete structural breakdown documented
- [ ] **Improvement Recommendations**: Specific suggestions for strengthening argument

## Practical Application

### Argument Construction

- [ ] **Pre-Writing Analysis**: Outline argument using Damer's criteria before writing
- [ ] **Criterion Checking**: Systematically check each criterion during construction
- [ ] **Fallacy Prevention**: Actively avoid common fallacies in each category
- [ ] **Counterargument Planning**: Plan responses to likely counterarguments
- [ ] **Revision Focus**: Use criteria as revision checklist

### Argument Evaluation

- [ ] **Systematic Review**: Apply all five criteria systematically
- [ ] **Charitable Interpretation**: Apply principle of charity before criticism
- [ ] **Constructive Criticism**: Focus on helping strengthen arguments, not just attacking
- [ ] **Alternative Solutions**: Suggest improvements for identified problems
- [ ] **Overall Assessment**: Provide fair overall assessment based on criteria

### Discussion Management

- [ ] **Code Application**: Apply 12-principle code throughout discussion
- [ ] **Focus Maintenance**: Keep discussion focused on arguments, not personalities
- [ ] **Progress Tracking**: Monitor whether discussion advances understanding
- [ ] **Resolution Recognition**: Recognize when sufficient evidence supports conclusion
- [ ] **Graceful Concession**: Accept when your position has been effectively challenged

## Additional Fallacy Categories

### Ambiguity and Linguistic Fallacies

- [ ] **Equivocation**: Same word used with different meanings in argument
- [ ] **Amphiboly**: Grammatical ambiguity leading to misinterpretation
- [ ] **Accent**: Misleading through emphasis or pronunciation
- [ ] **Category Error**: Applying inappropriate categories or concepts
- [ ] **Reification**: Treating abstract concepts as concrete entities
- [ ] **Definitional Problems**: Exploiting unclear or shifting definitions

### Distraction and Misdirection

- [ ] **Moving the Goalposts**: Changing standards or criteria when convenient
- [ ] **Topic Shifting**: Changing subject to avoid addressing argument
- [ ] **Complexity Introduction**: Making arguments unnecessarily complex to confuse
- [ ] **Selective Quotation**: Using quotes out of context
- [ ] **Attribution Errors**: Attributing positions opponent doesn't hold

### Pattern Analysis Framework

- [ ] **Fallacy Frequency**: Track which fallacies appear most often
- [ ] **Context Patterns**: Note whether certain topics trigger specific fallacies
- [ ] **Severity Assessment**: Evaluate how much fallacies weaken arguments
- [ ] **Intentionality**: Assess whether fallacies appear deliberate or unconscious
- [ ] **Educational Opportunities**: Identify areas where logic education would help

### Comprehensive Documentation

- [ ] **Fallacy Catalog**: Complete list of identified fallacies with examples
- [ ] **Context Impact**: How context affects fallacy interpretation
- [ ] **Pattern Summary**: Overall trends in reasoning quality
- [ ] **Credibility Assessment**: How fallacies affect source credibility
- [ ] **Improvement Recommendations**: Specific suggestions for strengthening arguments

This checklist provides a comprehensive framework for argument analysis based on T. Edward Damer's systematic approach to identifying faulty reasoning and constructing sound arguments, enhanced with additional fallacy categories and assessment methods.
