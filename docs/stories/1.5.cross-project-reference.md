### Data Models

**Project Relationship Model** [Extension of architecture.md Project Metadata Model for Story 1.5]:
- `project_links`: array - List of connected projects with relationship metadata
- `relationship_type`: enum - Classification of relationship (dependency, reference, collaboration, successor, parent, child)
- `link_created`: timestamp - When relationship was established
- `link_purpose`: string - Human-readable reason for project connection
- `link_strength`: enum - Relationship intensity (weak, moderate, strong, critical)
- `dependency_order`: number - Sequencing for dependency resolution and workflow ordering
- `collaboration_status`: enum - Current collaboration state (active, inactive, completed, archived)

**Cross-Project Reference Model** [New for Story 1.5]:
- `reference_id`: string - Unique identifier for cross-project reference
- `source_project`: string - Project containing the original reference or insight
- `target_projects`: array - Projects referencing or dependent on source content
- `reference_type`: enum - Type of cross-reference (source, analysis, insight, methodology, template)
- `reference_path`: string - Specific file or content location within source project
- `reference_context`: string - Description of how reference is used in target projects
- `bidirectional`: boolean - Whether reference relationship is mutual
- `reference_strength`: number - Weight of reference importance for dependency analysis
- `last_validated`: timestamp - Most recent reference integrity check

**Project Dependency Graph Model** [New for Story 1.5]:
- `graph_id`: string - Unique identifier for dependency graph
- `nodes`: array - List of projects in dependency relationship
- `edges`: array - Directed connections between projects with dependency metadata
- `cycles`: array - Detected circular dependencies requiring resolution
- `critical_path`: array - Longest dependency chain affecting project completion
- `dependency_health`: enum - Overall graph health status (healthy, warnings, critical, broken)
- `last_analyzed`: timestamp - Most recent dependency analysis execution

**Cross-Project Insight Model** [New for Story 1.5]:
- `insight_id`: string - Unique identifier for cross-project insight
- `contributing_projects`: array - Projects contributing to combined insight
- `insight_pattern`: string - Identified pattern or theme across projects
- `pattern_strength`: number - Statistical significance of identified pattern
- `insight_evolution`: array - Timeline of insight development across projects
- `collaborative_annotations`: array - Team comments and shared insights
- `aggregated_sources`: array - Combined source materials supporting insight
- `meta_analysis_results`: object - Statistical analysis of combined project data
