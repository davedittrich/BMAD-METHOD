# project-insights

## Task Overview

Perform sophisticated cross-project analysis and pattern recognition, aggregating insights from multiple related projects with comprehensive relationship visualization and collaborative knowledge synthesis for advanced research intelligence.

## Instructions

1. **Project Network Discovery**
   - Identify target projects for cross-project analysis (use active project context and linked projects)
   - Analyze project relationship graph from `config/project-graph.json` for analysis scope determination
   - Validate project accessibility and analysis readiness across identified network
   - Determine analysis boundaries based on relationship strength and type

2. **Cross-Project Pattern Recognition**
   - Aggregate analysis content from related projects' `analyses/` directories
   - Identify recurring themes, methodologies, and research patterns across project boundaries
   - Perform semantic analysis of combined research content for insight pattern detection
   - Calculate pattern strength and statistical significance across contributing projects

3. **Relationship Strength Analysis**
   - Analyze shared sources and cross-references between projects using source management data
   - Calculate collaboration patterns based on shared resources and annotation interactions
   - Measure research evolution and insight development across project timelines
   - Quantify relationship strength based on content overlap and methodological alignment

4. **Insight Aggregation and Synthesis**
   - Combine analysis results from multiple projects with proper source attribution
   - Create meta-analysis summaries preserving individual project context and contributions
   - Generate cross-project insight synthesis with collaborative annotation integration
   - Maintain research lineage and traceability across aggregated insights

5. **Trend Analysis and Evolution Tracking**
   - Analyze research evolution patterns across project timelines and relationship development
   - Identify research trends and methodological progression across related projects
   - Track insight development and knowledge accumulation over time
   - Generate timeline visualization of cross-project research evolution

6. **Collaborative Knowledge Integration**
   - Integrate collaborative annotations and shared insights from project collaboration framework
   - Aggregate team contributions and multi-researcher perspectives across project boundaries
   - Synthesize collaborative knowledge with individual project insights for comprehensive analysis
   - Maintain contributor attribution and collaborative history tracking

7. **Cross-Project Visualization and Reporting**
   - Generate relationship graphs showing project connections and dependency structures
   - Create insight aggregation reports with pattern recognition results and trend analysis
   - Produce cross-project timeline visualization showing research evolution and interconnections
   - Generate collaborative knowledge synthesis reports with comprehensive attribution

8. **Integration with Analysis Workflows**
   - Utilize enhanced tasks from Story 1.2 for consistent analysis processing across projects
   - Integrate with project context management from Story 1.3 for seamless cross-project navigation
   - Leverage source management from Story 1.4 for cross-project source relationship analysis
   - Maintain compatibility with project infrastructure and metadata systems

9. **Validation and Quality Assurance**
   - Verify cross-project analysis results maintain proper source attribution and context
   - Validate insight aggregation preserves individual project integrity and contributions
   - Confirm collaborative knowledge synthesis maintains contributor recognition
   - Ensure analysis quality and statistical significance of identified patterns
