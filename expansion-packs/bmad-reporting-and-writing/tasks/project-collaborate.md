# project-collaborate

## Task Overview

Enable sophisticated team coordination and knowledge sharing across related research projects with collaborative annotation systems, shared resource management, and comprehensive collaboration history tracking for enhanced multi-researcher workflows.

## Instructions

1. **Collaboration Space Initialization**
   - Establish collaborative workspace for linked projects using relationship metadata
   - Create shared collaboration areas in `config/collaboration-spaces.json`
   - Initialize team coordination framework with participant tracking and role management
   - Set up collaborative annotation system for cross-project insights and shared knowledge

2. **Team Coordination and Management**
   - Identify project participants and research team members across related projects
   - Establish collaboration roles (lead researcher, collaborator, contributor, reviewer)
   - Create team communication channels and coordination mechanisms within BMAD framework
   - Initialize collaborative workflow management with task assignment and progress tracking

3. **Collaborative Annotation System**
   - Create shared annotation framework for cross-project insights and commentary
   - Implement annotation threading with reply and discussion capabilities
   - Establish annotation categorization (insights, questions, references, methodology notes)
   - Integrate annotations with existing project analyses and research materials

4. **Knowledge Sharing and Resource Management**
   - Create shared resource repository for templates, methodologies, and best practices
   - Implement knowledge inheritance system for insight propagation across related projects
   - Establish shared source collection with cross-project access and reference tracking
   - Create collaborative research methodology library with version control and evolution tracking

5. **Collaborative History and Attribution**
   - Track collaboration events and team interactions with comprehensive logging
   - Maintain contributor attribution for shared insights and collaborative developments
   - Create collaboration timeline with milestone tracking and team coordination events
   - Implement change logging for collaborative modifications and knowledge evolution

6. **Cross-Project Communication Framework**
   - Establish communication channels for project updates and coordination
   - Create notification system for collaborative events and shared resource updates
   - Implement discussion threading for research questions and methodology debates
   - Integrate communication with existing project context and relationship management

7. **Shared Analysis and Synthesis Workflows**
   - Create collaborative analysis workflows combining multiple researcher perspectives
   - Implement shared synthesis capabilities for cross-project insight development
   - Establish collaborative review processes for research quality and methodology validation
   - Create team-based analysis assignment and progress tracking systems

8. **Integration with Project Relationship Network**
   - Utilize project linking from previous tasks for collaboration scope determination
   - Integrate with cross-project insights for collaborative knowledge synthesis
   - Maintain compatibility with project context management and navigation systems
   - Ensure collaboration features respect project boundaries while enabling knowledge sharing

9. **Collaboration Quality and Validation**
   - Implement collaboration effectiveness metrics and team productivity analysis
   - Create validation systems for collaborative contributions and shared knowledge quality
   - Establish conflict resolution mechanisms for research disagreements and methodology differences
   - Monitor collaboration health with participation tracking and engagement measurement
