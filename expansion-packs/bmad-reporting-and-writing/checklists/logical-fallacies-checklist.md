# Logical Fallacies Assessment Checklist

Use this checklist to systematically identify and analyze logical fallacies in arguments, statements, or reasoning patterns.

## Formal Fallacies

### Syllogistic Errors

- [ ] **Affirming the consequent**: "If A then B; B; therefore A"
- [ ] **Denying the antecedent**: "If A then B; not A; therefore not B"
- [ ] **Undistributed middle**: Middle term not distributed in at least one premise
- [ ] **Illicit major/minor**: Major or minor term distributed in conclusion but not premise
- [ ] **Exclusive premises**: Both premises negative or particular

### Propositional Logic Errors

- [ ] **Invalid inference patterns**: Conclusions don't follow from premises
- [ ] **Modal fallacies**: Incorrect reasoning about necessity and possibility
- [ ] **Temporal fallacies**: Incorrect reasoning about time relationships
- [ ] **Causal fallacies**: Invalid causal inference patterns
- [ ] **Conditional fallacies**: Misuse of conditional statements

### Documentation

- [ ] **Formal structure**: Diagram of argument's formal logical structure
- [ ] **Validity assessment**: Whether conclusions follow from premises
- [ ] **Soundness evaluation**: Whether premises are actually true
- [ ] **Repair possibilities**: How argument could be made valid

## Informal Fallacies - Relevance

### Ad Hominem Attacks

- [ ] **Abusive ad hominem**: Attacking person rather than argument
- [ ] **Circumstantial ad hominem**: Attacking person's circumstances or motivations
- [ ] **Tu quoque**: "You too" - pointing out opponent's hypocrisy
- [ ] **Poisoning the well**: Pre-emptive attack on opponent's credibility
- [ ] **Genetic fallacy**: Attacking argument's origin rather than content

### Appeals to Irrelevant Authority

- [ ] **Appeal to false authority**: Citing inappropriate or unqualified authority
- [ ] **Appeal to popularity**: Argument from majority opinion
- [ ] **Appeal to tradition**: Argument that old ways are necessarily correct
- [ ] **Appeal to novelty**: Argument that new ideas are necessarily better
- [ ] **Bandwagon fallacy**: Joining popular opinion without evaluation

### Emotional Appeals

- [ ] **Appeal to fear**: Using fear to avoid rational evaluation
- [ ] **Appeal to pity**: Evoking sympathy instead of providing evidence
- [ ] **Appeal to flattery**: Using praise to avoid critical evaluation
- [ ] **Appeal to consequences**: Arguing based on consequences rather than truth
- [ ] **Appeal to force**: Using threats instead of reasoning

### Documentation

- [ ] **Relevance analysis**: How premises relate to conclusions
- [ ] **Distraction identification**: Elements distracting from main argument
- [ ] **Emotional manipulation**: Ways emotions are used inappropriately
- [ ] **Authority evaluation**: Assessment of cited authorities' qualifications

## Informal Fallacies - Weak Induction

### Hasty Generalization

- [ ] **Small sample size**: Drawing conclusions from insufficient evidence
- [ ] **Unrepresentative samples**: Generalizing from biased or atypical cases
- [ ] **Cherry-picking**: Selecting only favorable evidence
- [ ] **Anecdotal evidence**: Over-relying on personal stories or isolated cases
- [ ] **Statistical misrepresentation**: Misusing statistics or data

### False Cause Fallacies

- [ ] **Post hoc ergo propter hoc**: Assuming causation from temporal sequence
- [ ] **Correlation implies causation**: Confusing correlation with causation
- [ ] **Oversimplified cause**: Ignoring multiple causal factors
- [ ] **Wrong direction**: Confusing cause and effect
- [ ] **Common cause neglect**: Ignoring shared causal factors

### Weak Analogy

- [ ] **Inappropriate comparisons**: Comparing fundamentally different things
- [ ] **Ignoring relevant differences**: Overlooking important distinctions
- [ ] **Overextending analogies**: Pushing analogies beyond their valid scope
- [ ] **False equivalence**: Treating unequal things as equivalent
- [ ] **Metaphorical fallacies**: Confusing metaphor with literal truth

### Documentation

- [ ] **Evidence quality**: Assessment of evidence strength and representativeness
- [ ] **Causal analysis**: Evaluation of causal claims and relationships
- [ ] **Analogy assessment**: Evaluation of comparison appropriateness
- [ ] **Inductive strength**: Overall strength of inductive reasoning

## Informal Fallacies - Presumption

### Begging the Question

- [ ] **Circular reasoning**: Conclusion assumed in premises
- [ ] **Question-begging epithets**: Using loaded terms that assume conclusion
- [ ] **Complex question**: Questions containing unjustified assumptions
- [ ] **Loaded questions**: Questions with built-in controversial assumptions
- [ ] **False dichotomy**: Presenting limited options when more exist

### False Assumptions

- [ ] **Assumption of false premises**: Building arguments on questionable foundations
- [ ] **Suppressed evidence**: Ignoring relevant contrary evidence
- [ ] **Accident fallacy**: Applying general rules inappropriately to special cases
- [ ] **Converse accident**: Generalizing inappropriately from special cases
- [ ] **Division/composition**: Inappropriate attribution between parts and wholes

### Slippery Slope

- [ ] **Causal slippery slope**: Assuming inevitable causal chains
- [ ] **Conceptual slippery slope**: Assuming concepts can't be distinguished
- [ ] **Precedent slippery slope**: Assuming precedents lead inevitably to extremes
- [ ] **Fairness slippery slope**: Assuming equal treatment requires identical treatment
- [ ] **Sorites paradox**: Exploiting vagueness to avoid clear distinctions

### Documentation

- [ ] **Assumption identification**: Hidden or questionable assumptions in arguments
- [ ] **Alternative possibilities**: Other options ignored or dismissed
- [ ] **Slope analysis**: Whether claimed consequences actually follow
- [ ] **Premise evaluation**: Truth and relevance of stated and unstated premises

## Ambiguity and Linguistic Fallacies

### Equivocation

- [ ] **Word meaning shifts**: Same word used with different meanings
- [ ] **Context shifting**: Meaning changes based on context
- [ ] **Grammatical ambiguity**: Ambiguous sentence structure
- [ ] **Emphasis fallacies**: Changing meaning through emphasis
- [ ] **Accent fallacies**: Misleading through pronunciation or stress

### Vagueness Exploitation

- [ ] **Sorites fallacies**: Exploiting vague boundaries
- [ ] **Heap fallacies**: Assuming sharp boundaries where none exist
- [ ] **Definitional problems**: Exploiting unclear definitions
- [ ] **Conceptual stretching**: Extending concepts beyond normal usage
- [ ] **Category errors**: Applying inappropriate categories

### Semantic Fallacies

- [ ] **Reification**: Treating abstract concepts as concrete entities
- [ ] **Hypostatization**: Giving abstract ideas inappropriate concrete properties
- [ ] **Pathetic fallacy**: Attributing human characteristics to non-human things
- [ ] **Misplaced concreteness**: Treating models or theories as literal reality
- [ ] **Word magic**: Believing words have magical power over reality

### Documentation

- [ ] **Meaning analysis**: How word meanings shift or remain unclear
- [ ] **Clarity assessment**: Whether key terms are defined and used consistently
- [ ] **Context evaluation**: How context affects interpretation
- [ ] **Communication effectiveness**: Whether argument communicates clearly

## Fallacies of Distraction

### Red Herring

- [ ] **Topic shifting**: Changing subject to avoid addressing argument
- [ ] **Irrelevant information**: Introducing irrelevant but distracting facts
- [ ] **Emotional distractions**: Using emotions to divert attention
- [ ] **Complexity introduction**: Making arguments unnecessarily complex
- [ ] **Tangential discussions**: Going off on unrelated tangents

### Straw Man

- [ ] **Misrepresenting positions**: Distorting opponent's actual position
- [ ] **Oversimplification**: Reducing complex positions to simple caricatures
- [ ] **Selective quotation**: Using quotes out of context
- [ ] **Weak version selection**: Attacking weakest version of opponent's argument
- [ ] **Attribution errors**: Attributing positions opponent doesn't hold

### Moving the Goalposts

- [ ] **Changing standards**: Shifting criteria when convenient
- [ ] **Raising the bar**: Demanding increasingly higher levels of proof
- [ ] **Definition shifting**: Changing definitions mid-argument
- [ ] **Scope creep**: Expanding argument scope to avoid refutation
- [ ] **Victory condition changes**: Changing what constitutes winning

### Documentation

- [ ] **Focus tracking**: Whether arguments stay on topic
- [ ] **Position accuracy**: Whether opposing positions are represented fairly
- [ ] **Standard consistency**: Whether evaluation criteria remain consistent
- [ ] **Distraction identification**: Methods used to avoid direct engagement
