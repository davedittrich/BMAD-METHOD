# KDP Cover Ready Checklist

Use this checklist to ensure your cover design meets Amazon KDP print specifications and requirements before finalizing publication.

## Technical Specifications

- [ ] **Correct trim size**: Cover matches exact trim size selected for book
- [ ] **Bleed margins applied**: 0.125" bleed on all edges (top, bottom, outside)
- [ ] **300 DPI resolution**: All images and text at 300 DPI minimum
- [ ] **CMYK color profile**: Print PDF uses CMYK color mode (not RGB)
- [ ] **File size under limit**: PDF file size less than 40MB
- [ ] **No transparent layers**: All transparency flattened for print

## Spine Requirements

- [ ] **Spine width accurate**: Spine width matches calculated spine width for page count
- [ ] **Text safety margins**: All spine text at least 0.0625" from spine edges
- [ ] **Spine text readable**: Text large enough to read when printed
- [ ] **Spine alignment**: Text properly centered and aligned on spine

## Cover Design Standards

- [ ] **Front cover legibility**: Title and author name readable at thumbnail size
- [ ] **Back cover legibility**: All back cover text readable when printed
- [ ] **Barcode zone clear**: Lower right back cover area clear for barcode placement
- [ ] **Professional appearance**: Design looks professional and market-appropriate
- [ ] **Genre appropriate**: Visual style matches target genre expectations

## Quality Control

- [ ] **Text proofreading**: All cover text proofread for spelling and accuracy
- [ ] **Color consistency**: Colors appear consistent across front, spine, and back
- [ ] **Image quality**: All images sharp and high quality when viewed at 100%
- [ ] **Alignment check**: All elements properly aligned and positioned
- [ ] **Print preview**: Design reviewed in print preview mode

## KDP Upload Requirements

- [ ] **Single PDF file**: Cover supplied as single PDF file
- [ ] **Correct orientation**: PDF oriented correctly for upload
- [ ] **No crop marks**: Crop marks removed from final file
- [ ] **Embedded fonts**: All fonts embedded in PDF
- [ ] **Proper naming**: File named clearly for identification

## Final Verification

- [ ] **Template compliance**: Design matches KDP cover template exactly
- [ ] **Proof quality**: Design quality suitable for professional publication
- [ ] **Market readiness**: Cover competitive with similar books in genre
- [ ] **Print test considered**: Physical proof copy ordered if needed
- [ ] **Backup saved**: High-resolution source files backed up safely
