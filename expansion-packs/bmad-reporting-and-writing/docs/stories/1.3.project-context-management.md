# Story 1.3: Project Context Management

## Status
Review

## Story
**As a** research journalist,  
**I want** to seamlessly switch between project contexts and receive project-aware guidance throughout my workflows,  
**so that** I can maintain focus on the current investigation while accessing relevant project information and recommendations.

## Acceptance Criteria
1. `project-switch` task enables changing active project context with persistence across workflow sessions
2. `project-status` task provides comprehensive project progress overview with analysis inventory and recommendations
3. Project context persistence maintains active project state between task executions and CLI sessions
4. Project-aware guidance appears in task outputs when project context is active
5. Context-aware file discovery helps locate and reference project materials across workflow sessions
6. Smooth integration with Stories 1.1 and 1.2 infrastructure without disrupting existing functionality

### Data Models

**Project Context State Model** [New for Story 1.3]:
- `active_project`: string - Currently active project name (null if no project active)
- `context_set_date`: timestamp - When context was last activated
- `session_id`: string - Identifier for current workflow session
- `last_accessed`: timestamp - Most recent context usage for cleanup purposes
- `context_source`: enum - How context was set (manual, auto-detected, restored)

**Enhanced Project Metadata Model** [Extension of architecture.md model]:
- Extends existing Project Metadata Model with context management fields
- `last_active`: timestamp - When project was last set as active context
- `activity_log`: array - Recent project operations for status reporting
- `workflow_stage`: string - Current research phase for guidance recommendations
- `next_suggestions`: array - Contextual next steps based on project progress

**Project Context Persistence** [Source: architecture.md#project-context-manager-component]:
- Context storage location: `config/active-project.json` (global configuration)
- Session-based persistence across CLI executions
- Validation against existing project directory structure
- Automatic cleanup for deleted or invalid projects
